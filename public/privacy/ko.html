2. 직접 등록한 식품과 사진

식품명, 사진, 유통기한, 보관 위치와 사용 기록은 기기에 저장되며, iCloud를 사용하는 경우 사용자의 Apple 계정으로 동기화됩니다. 사진의 글자 인식과 배경 제거는 기기에서 처리합니다. 해당 사진, 인식한 원문과 식품명을 Amplitude로 전송하지 않습니다. iCloud는 Pantrip의 소셜 로그인 계정과 별개입니다.

3. 계정·결제·보상을 위해 처리하는 정보

서버는 익명 계정 ID, 인증 토큰, 계정 생성·접속 정보와 연결한 로그인 제공자의 식별자를 처리합니다. Apple·Google을 연결하면 제공자가 전달한 이메일, 이름 등 프로필 정보가 인증 시스템에 저장될 수 있습니다. 소셜 로그인 비밀번호는 받지 않습니다.

포인트 잔액, 주방·상품·장식 소유권, 거래 식별자·상품 ID·시각과 보상 지급 내역을 서버에서 처리합니다. 카드 번호는 운영자가 받지 않습니다. 활동 보상 검증을 위해 서버에 식품 내부 ID, 등록·완료 여부와 시각, 유통기한, 시간대, 보관 위치, 사진 유무, 바코드 해시 및 주방 이름 해시를 전송합니다. 식품 사진 원본과 식품명 자체를 이 보상 API로 전송하지 않습니다. 해시와 활동 정보도 계정에 연결된 개인정보로 보호합니다.

정보는 앱에서 직접 입력하거나 기능을 사용할 때, 연결한 로그인·결제·광고 서비스의 응답을 받을 때, 또는 이메일로 문의할 때 수집됩니다. 기기 권한을 허용한 것과 이용 분석·광고에 관한 선택은 별개입니다.

4. 선택 기능과 기기 권한

카메라는 촬영·바코드 인식, 사진 접근은 선택한 사진 등록, 알림은 유통기한 안내에 사용합니다. iOS 설정에서 권한을 변경할 수 있고 거절해도 수동 등록은 가능합니다.

온라인 검색을 실행하면 바코드 또는 입력한 검색어, 검색 언어와 IP 주소 등 통신 정보가 Open Food Facts에 전달됩니다. 사진은 이 검색에 업로드하지 않습니다. 온라인 검색을 실행하지 않으면 해당 요청은 보내지 않습니다.

5. 이용 분석과 광고

Amplitude로 화면 이동, 식품 등록 방식(수동·카메라·사진·바코드), 온라인 검색 시도와 결과, 주방·상점·업적·광고·구매 흐름의 이벤트를 자동 수집합니다. 수집에는 분석 식별자, 앱 버전, 기기·운영체제 정보와 제한된 선택값·성공 여부·소요 시간이 포함됩니다. 별도 동의 팝업은 표시하지 않습니다. 사진, 식품명, 입력한 문장, 바코드 원문, 이메일과 인증 토큰은 분석 속성으로 보내지 않습니다. IP 주소를 이용한 자동 위치 추론은 SDK 설정에서 비활성화합니다. 전송 서버는 연결에 필요한 통신 정보를 처리할 수 있습니다. 새 계정 연동 분석은 expirycheck:<계정 UUID> 형태의 가명 식별자를 사용하며 이메일이나 이름을 분석 ID로 쓰지 않습니다.

보상 광고는 사용자가 광고 보기를 선택할 때 제공합니다. Google의 동의 안내가 필요한 경우 해당 안내를 표시하며, iOS 추적 권한도 별도로 요청합니다. 추적 권한 거절만으로 광고 보상을 제한하지 않습니다. 현재 앱은 비개인화 광고를 요청합니다. 광고 SDK는 IP 주소, 기기·앱 정보, 광고 노출·반응 및 허용된 식별자를 처리할 수 있습니다. 필요한 경우 앱의 광고 개인정보 설정에서 선택을 변경할 수 있습니다.
